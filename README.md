# 業種別ホームページ見本帳

7業種 × 5パターン、計35のサンプルサイトです。店名・住所・電話番号はすべて架空です。
`index.html` を開くと、全サイトの一覧から各ページへ移動できます。

## フォルダ構成

```
index.html        一覧ページ
salon/            美容室
build/            工務店
cafe/             カフェ
pilates/          ピラティス
clinic/           クリニック
shop/             通販サイト
corp/             会社
  01.html  ナチュラル（業種らしい配色の基本形）
  02.html  高級感（暗色・明朝体・全面写真のヒーロー）
  03.html  ポップ（角丸カード・波形の区切り・スマホ下部に固定ボタン）
  04.html  ミニマル（大きな文字・見出しと本文の2カラム）
  05.html  和モダン（縦書き見出し・左サイドバー）
_generator/       02〜05を生成するスクリプト
```

各HTMLは1ファイルで完結しています（CSS・JavaScriptを内包、外部読み込みはGoogle Fontsのみ）。
そのままレンタルサーバーやGitHub Pagesに置けば表示できます。

## 納品時に差し替える箇所

- 店名・住所・電話番号・営業時間・料金
- 写真枠（`写真：〇〇（差し替え）` と表示されているグラデーションの箱）を `<img>` に置き換え
- お問い合わせフォームの送信先（現在は送信されないデモ動作。Formspree、Googleフォーム、サーバーのPHPなどに接続）
- 通販サイトのカートは見た目だけのデモです。実際の販売にはShopify、BASE、STORESなどと連携します

## 内容をまとめて変える（02〜05）

`_generator/data.py` の文章や料金を書き換えてから、次を実行すると02〜05と一覧ページが作り直されます。

```
cd _generator
python3 build.py
python3 index.py
```

01は個別に手作りしているため、直接HTMLを編集してください。

## GitHub Pagesで公開する

リポジトリの Settings → Pages → Branch を `main`、フォルダを `/ (root)` にして保存すると、
数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で一覧ページが見られます。
